抖音关注助手 · 手机免电脑版

在手机浏览器里直接抓未读、批量取关、搜索关注 —— 全程不需要电脑

为什么以前必须要电脑

网页有一条死规矩：一个网页不能操控另一个网站的页面。抖音的关注按钮在 douyin.com 里，你的工具页在别处，中间隔着浏览器的安全沙箱，谁也碰不到谁。

所以之前的做法是：让电脑上那台已登录的浏览器去点按钮，你的手机只当遥控器。

现在的做法：让脚本直接跑在手机浏览器的抖音页面里。这样它和抖音「同源」，请求自带你的登录态，点按钮也是真人在真浏览器里点 —— 抖音风控从根上就不存在了，电脑也就不需要了。

1 准备：手机浏览器打开抖音网页版

  1. 用手机浏览器（Chrome / Edge / 三星 / 夸克等均可）访问 www.douyin.com
  2. 必须开启「桌面版网站」：浏览器菜单里勾选（Chrome 是右上角 ⋮ → 桌面版网站）关键
  3. 在页面上登录抖音（手机号验证码 / 密码 / 扫码均可）
  4. 确认地址栏显示的是 www.douyin.com，而不是跳到下载 App 的页面
如果一直被强制跳「下载抖音 App」，说明桌面模式没生效，回到第 2 步重新勾选。

2 安装脚本（两种方式，选一个）

方式 A · 书签小工具推荐 · 零安装

  1. 先复制下面这段代码
  2. 给浏览器新建一个书签，名字随便起（比如「抖音助手」），把网址栏里原来的地址删掉，粘贴这段内容并保存
  3. 以后在抖音页面上点一下这个书签，右下角就会出现 🎯 按钮
脚本本体托管在 jsDelivr CDN，以后我更新了脚本，你这个书签不用改，自动就是新版。
个别手机浏览器的书签不允许执行代码（点书签没反应）。遇到这种情况改用方式 B。

  2. 在里面装 Tampermonkey（Kiwi 可从 Chrome 应用商店装）或 Violentmonkey（Firefox 附加组件）

3 怎么用

按钮作用

🔍 抓最新未读逐个账号抓最新视频，实时显示进度「已抓 N/M」，自动防风控间隔

常见问题

Q：抓未读要多久？
约 400 个账号、每个间隔 1~2.5 秒，大约 10~15 分钟。期间把手机屏幕保持亮着、别切走这个标签页。

Q：显示失败很多？
多半是抖音风控冷却中，过 20~30 分钟再抓一次。脚本本身遇错会自动退避等待，不会硬闯。

Q：取关失败 / 提示验证码？
取关是用「隐藏 iframe 打开对方主页 → 点真实关注按钮」实现的。抖音对新建的页面上下文比较敏感，你当天抓取频繁时会弹「验证码中间页」导致失败。
解决办法（任选）：
① 点账号右边的 🌐 主页，在真实标签页里手动点一下「已关注」—— 真实页面不会被验证码拦；
② 等 20~30 分钟风控冷却后再用 ✕ 取关。
这是抖音的风控策略，不是脚本坏了；同一台电脑那套也一样会被拦。

Q：数据存在哪？
存在你手机浏览器的 localStorage 里（抖音域名下）。推到 GitHub 后，原来的手机端 HTML 也能看到同一份数据。

Q：换手机/清缓存会丢吗？
会。所以抓完记得点「☁️ 推到 GitHub」；在新手机上先点「🔄 同步」或从 GitHub 拉一次即可。

和原来那套的关系

电脑上那套服务可以彻底不用了。本脚本导出的数据格式和原来完全一致（unread.json），原来的手机端 HTML 照常能读。

如果你还想留着电脑端自动跑，也不冲突 —— 两边推的是同一份 unread.json，谁后推谁为准。
